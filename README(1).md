# Relationship & Trust Manager (by Varun)

A privacy-focused, single-page web application to store, categorize, and organize personal contacts based on Trust Tiers, Closeness Ratings, and Relationship Links.

## 🚀 Features

- **🔒 PIN Security Lock**: Default PIN is `1234` (Can be updated in settings).
- **🛡️ 5-Level Trust Tiers**: Categorize contacts from Tier 1 (Caution) to Tier 5 (Absolute / Vault Trust).
- **⭐ Closeness Rating**: Rate relationships on a 1–5 star scale.
- **🏷️ Relationship Links & Tags**: Quick tags for College, Work, VIP, Emergency, and custom options.
- **🎂 Smart Birthday Reminders**: Banner alert for birthdays in the next 30 days.
- **💾 LocalStorage Auto-Save**: Persistent offline storage directly inside your browser.
- **📦 Backup & Restore**: Export/Import contact directory as JSON.

## 📁 Repository Contents

- `index.html` - Complete web app (HTML + Tailwind CSS + JavaScript).
- `README.md` - Documentation and setup instructions.

## 🌐 Deploy to GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md`.
3. Go to **Settings** > **Pages**.
4. Set source branch to `main` (or `master`) and save.
5. Your web app will be live instantly!
